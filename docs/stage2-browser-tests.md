# 阶段 2 浏览器回归用例

使用独立验收数据库与合成图片；不发送模型请求。

## U01 未保存参数的恢复路径

1. 新建一笔空订单，不上传参考图。
2. 在创作要求中选择“跟参考图”。
3. 此时来源列表为空，保存会被必填校验阻止。
4. 应能撤销尚未保存的修改，恢复已保存参数，然后上传参考图。
5. 再次选择参考图来源并保存，界面解除未保存状态。

验收前代码检查发现：步骤 4 无撤销入口，未保存参数又会禁用素材区；需要补入口并实测。

2026-09-20 复验通过：加入“撤销未保存修改”，无参考图时选择该模式，再撤销后上传按钮恢复可用。已保存的来源参数保持不变。

## U02 订单及素材往返

新建中文客户订单 → 上传合成主照片 → 设置发型来源 → 保存为待生成 → 预览创作要求 → 回列表搜索 → 重新打开详情，检查数据保留。移出当前引用素材后应提示重新选择，恢复后不自动恢复来源参数。

2026-09-20：中文新建、发型/参考图服装来源、去掉眼镜、额外要求保存、待生成、预览、搜索、重新打开、移出恢复全部通过。浏览器文件选择因扩展没有文件 URL 权限失败；合成图片改经同源 HTTP 上传，文件选择到上传按钮提交这部分尚未完成浏览器验收。

## U03 布局与错误

检查桌面及 390px 窄屏的列表、新建和详情；关键按钮可见、无横向溢出。访问不存在的订单时显示错误并能回列表。生成入口明确尚未开放。

2026-09-20 通过：桌面及 390×844 截图检查无明显裁切；窄屏详情 documentElement.scrollWidth=375、innerWidth=390。不存在订单显示中文错误及关联 ID。验收后已恢复浏览器默认尺寸。

## U04 同源上传大小

通过前端 `/api` 转发上传超过 10 MiB、低于 20 MiB 的有效 PNG，必须成功且可读取完整图片；超过 20 MiB 返回 413。测试后保留隔离验收数据。

2026-09-20 首次失败：13,250,802 字节合成 PNG 返回 500，Next.js 日志报告默认 10 MiB 截断。按已读本地 Next.js 指南设置 proxyClientMaxBodySize=22 MiB 后，同一订单重试返回 201、内容逐字节相同，20 MiB+1 请求返回 413。没有跳过后端大小检查。

隔离数据：`storage/qa-stage2-20260920`，界面订单 `1fff475f-5e03-461a-9fb6-5ec4d687156c`，大文件订单 `29d33b9b-50ae-4aa1-a423-f2e24cadd900`。测试图片为色块及固定随机噪声，不含真实人物。13000/18000 验收服务已停止，既有 3000/8000 服务保留。
