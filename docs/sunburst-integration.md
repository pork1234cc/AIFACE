# Apii 三模型与完整图片接口适配

更新：2026-09-26。协议依据为根目录 `image2.md`。本次只使用模拟供应商测试，不宣称已经验证三个模型的真实账号权限、可用性或画质。

## 模型与切换

模型设置保留三个快捷选项：`gpt-image-2.0-4k`、`gpt-image-2`、`gpt-image-2.5-sunburst`。仍允许填写其他 Apii 模型 ID。接口根地址为 `https://ai.apii.cn`，不要填写 `/v1`。新安装默认 Sunburst；保存设置后新任务读取最新模型、质量和接口地址。

已提交订单任务及风格示意图使用请求快照；查询继续使用原接口地址，订单失败重试也保留原请求快照。要用另一模型重新创作，应提交新任务。API Key 仍为同一 Apii 账号凭据，不是每模型独立密钥；更换 Key 前应完成运行中的任务。

当前工作区 `.env` 已切换到 Sunburst，原文件备份在忽略提交的 `storage/config-backups/`；接口地址、密钥和其他配置保持原值。升级前浏览器保存的待核对请求仍按旧字段摘要验证，新增默认字段不会触发假幂等冲突；非默认修改仍拒绝复用原请求键。人工关联远端任务同时核对模型和 generation/edit 类型。

三模型共用 Apii 协议适配器，不能将模型名称等同于 OpenAI 官方接口支持声明。供应商是否为某模型开放文生图、遮罩或自定义尺寸，以实际响应为准。此仓库只有 Sunburst 的完整当前文档，不对其他模型套用其总像素上限。

## 创作配置与流程

2026-09-26 布局纠正：输出比例、创作方式、风格、生图格式按此顺序放在同一行，使用四列布局，标签在各自下拉框上方；窄屏也保留四列。自定义比例或像素尺寸的补充输入，以及“返回方式与局部重绘”继续放在下方。以后增加基础选项时应统一检查整行布局，不能把输出比例单独拆到下一行。

配置继续存储于 `params_json` 和任务快照，不增加数据库表或迁移。

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `mode` | `edit` | `edit` 图片编辑；`generate` 无底图纯文生图 |
| `aspect_ratio` | `1:1` | 正整数 `n:m`，长短边比不超过3；空字符串表示使用 size |
| `size` | null | `宽x高`，宽高为16倍数；有效比例优先于 size |
| `response_format` | `url` | `url` 或 `b64_json` |
| `async_mode` | true | 映射供应商请求的 `async` |
| `mask` | null | 透明 PNG/WebP 的 Base64、Data URL 或公网 HTTPS 地址 |
| `mask_base_asset_id` | null | mask 对应的底图资产编号，必须与当前底图相同 |

纯文生图要求非空完整提示词，不接受底图、素材引用、区域要求和遮罩。页面切换模式时解除这些引用，原资产文件保留。创建使用 `/v1/images/generations`，不发送 `images`。生成结果照常进入版本历史和交付流程；点击“继续修改”自动转为图片编辑，以当前交付图为底图，并清除上一轮遮罩与区域要求。

图片编辑保留原有主照片和多素材流程，调用 `/v1/images/edits`；mask 作为独立字段，不混入 images 数组。现有区域识别继续用于文字定位；要执行遮罩重绘，请在“返回方式与局部重绘”中上传透明遮罩或填写地址。没有自动把所有区域识别结果发给模型。

遮罩完全透明区域表示重绘，不透明区域表示保留。本地内联遮罩在保存/预览/提交时检查图片格式、透明区域、尺寸及底图绑定；URL 遮罩在 Worker 中按现有安全下载规则读取并再次检查，转成 Base64 后提交。图片地址不允许账号信息、非443端口、非公网解析或重定向。URL 的内容在 Worker 读取前可能变化，要求固定输入时请上传本地遮罩。遮罩编辑不压缩或转向底图，避免透明度或 EXIF 变化造成坐标错位。

单张遮罩最多20 MiB。订单配置和任务快照保存其内联内容，会增加数据库及浏览器草稿体积；浏览器存储不足时仍可保存到订单，但需留意草稿未保存提示。Next.js 同源代理限制调整为30 MiB以容纳 Base64 膨胀。不得在日志中输出遮罩正文或结果图片正文。

## 尺寸

标准比例由模型解释。Sunburst 的11种标准比例尺寸见 `image2.md`，前端参考表已同步更新；界面公共比例选项只显示比例，不把 Sunburst 的像素数套用于其他模型。

自定义比例直接传给供应商计算尺寸；像素模式发送 size，不发送 aspect_ratio。Sunburst 像素模式在提交前检查单边≤3840、总像素≤3686400。其他模型只做通用格式及16倍数/比例检查，其尺寸能力由供应商判断。最终文件尺寸以实际返回为准。

## 返回、恢复与验证

默认异步提交返回 task_id，Worker 查询 queued/running/succeeded/failed。同步模式仍由独立 Worker 执行，网页接口保持快速返回本地任务；单次供应商读取超时600秒。同步等待会占用单 Worker，通常推荐异步。

成功响应统一接受单张 URL 或 Base64。远端异步结果为 result.data，同步结果为 data。URL 下载或 Base64 解码后复用图片校验、落盘和自动交付事务。Base64 只在待落盘阶段保留，成功后清除。同步结果可无远端编号；保存失败恢复原结果，不重新提交或计费。同步提交期间崩溃、超时且受理不明仍进入人工核对，不自动重发。
