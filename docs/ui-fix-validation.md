## 发现并修复的问题

从订单详情点击“创作流程”，URL 为 `/#workflow`，但菜单错误高亮 `/`。修复前用浏览器断言复现失败，修复后同一断言通过，且同页切换、后退/前进的高亮正确。

原因：Next.js 客户端跨页跳转可能在组件订阅之后设置 hash，且不触发原生 `hashchange`。两个跨页锚点改用原生链接，保证新页订阅能读取完整地址；同页保留 hash 事件，普通路由仍用 Next Link。代价是从订单页访问流程/风格会完整加载首页。没有修改 Next.js history 内部状态。
