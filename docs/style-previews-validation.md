# 风格示意图验收

日期：2026-09-21。

## 范围与交互

用户确认新增手动生成示意图，并要求入口位于风格名称同一行右侧、字体不加粗。已实现“生成示意图／重新生成示意图”，名称和按钮均使用普通字重。内置风格只读，入口仅在风格库自定义卡片出现，订单中显示生成后的封面。

固定底图见 [底图说明及完整生成提示词](../styles/preview/README.md)。点击后排入独立队列，页面自动刷新状态。成功替换封面，失败保留旧封面；风格版本改变显示“封面待更新”。保存提示词不触发模型请求。

## 使用

在风格库保存自定义风格后，点击名称右侧“生成示意图”。需保持后端和 Worker 运行，关闭页面不取消任务。下载失败用“恢复下载”；提交结果不明用“核对任务”，确认未受理后才可重试。卡片上的费用说明在点击前可见。
