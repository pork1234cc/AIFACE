# 自定义风格验收

日期：2026-09-21。

## 已确认范围

内置风格提示词不提供修改入口，另建自定义风格。自定义风格支持名称、可选说明、提示词的创建、查看、编辑和跨订单复用；没有删除或封面上传。内置风格由服务端强制只读。窗口宽度 440px，不显示编号与版本。

## 使用方式

风格库 → 新建自定义风格 → 填写并保存；订单配置 → 选择该风格 → 保存本次配置 → 预览或生成。修改自定义风格从其“查看提示词”进入，只影响以后生成；历史任务继续使用提交时的完整快照。
